## 🇹🇷 Türkçe



**SL-1200 MK7 BATTLE DSP**, MacBook Trackpad'in yüksek hassasiyetli çoklu dokunma (two-finger scroll) sensörlerini ve tarayıcı tabanlı **48kHz Web Audio API DSP** ses motorunu birleştirerek bilgisayarınızı profesyonel bir **Battle DJ Pikabına (Turntable)** dönüştüren, tek dosyada çalışan sıfır bağımlılıklı bir web uygulamasıdır.



### ✨ Öne Çıkan Özellikler

- **Çift Yönlü (İleri / Geri) Gerçek Zamanlı Buffer Scrubber:** Harici bir ses dosyasına ihtiyaç duymadan bellekte matematiksel olarak sentezlenen `AAHH`, `FRESH`, `BOOM SUB` ve `SIREN` vokal/efekt bankaları üzerinde kübik interpolasyonlu gerçek fiziksel plak sürtünmesi ve scratch deneyimi.

- **MacBook Trackpad & Fare Desteği:** Trackpad üzerinde iki parmağınızı yukarı-aşağı kaydırarak veya pikap plağını doğrudan tutarak yüksek hassasiyetli ileri (`FWD`) ve geri (`REV`) scratch hareketleri.

- **Battle DJ Crossfader & Fader Mekanikleri:**

  - **Transformer Cut (`SPACE`):** 2ms clickless (tıkırtısız) VCA kesme kapısı.

  - **3-Finger Crab Scratch (`Z` / `X` / `C`):** Hızlı parmak vuruşlarıyla profesyonel crab kesmeleri.

  - **Hamster Switch (`H`):** Battle DJ'ler için crossfader kesme yönünü tersine çeviren mod.

- **Melankolia Boom-Bap Sequencer:** D-Phrygian makamında melankolik ud/Rhodes arpeji, analog kick, yaylı trampet (snare) ve sub-bass içeren dahili beat motoru.

- **YouTube Entegrasyonu:** İstediğiniz YouTube şarkı bağlantısını yükleyerek şarkı üzerine canlı scratch ve miks performansı.

- **Pro DJ Mikser Katı:** 3-Band Isolator EQ (`HI / MID / LOW KILL`), Rezonanslı Color Filter (`LPF / HPF`), Dub Delay, Ultra Pitch (`±16%`) ve 4-Pad MPC FX Sampler (`Q / W / E / R`).



### ⌨️ Klavye ve Trackpad Kontrolleri



| Kontrol / Tuş | İşlev |

| :--- | :--- |

| **Trackpad (2 Parmak Kaydırma)** | Plağa ileri (`FWD`) ve geri (`REV`) scratch uygular |

| **`SPACE` (Boşluk)** | Transformer Cut (Fader sesini anlık keser/açar) |

| **`Z` / `X` / `C`** | 3-Finger Crab Scratch kesmeleri |

| **`H`** | Hamster Switch (Fader yönünü ters çevirir) |

## 🇬🇧 English



**SL-1200 MK7 BATTLE DSP** is a zero-dependency, single-file web application that transforms your MacBook Trackpad's high-precision two-finger gesture sensors and browser-native **48kHz Web Audio API DSP** into a professional **Battle DJ Turntable & Scratch Workstation**.



### ✨ Key Features

- **Bidirectional Real-Time Buffer Scrubber:** Cubic-interpolated variable-speed audio scrubber reading synthesized `AAHH`, `FRESH`, `BOOM SUB`, and `SIREN` scratch banks forward and backward with authentic vinyl physics—no external audio files required.

- **MacBook Trackpad & Pointer Physics:** High-DPI two-finger trackpad scrolling or direct platter dragging with adjustable sensitivity and slipmat torque/inertia.

- **Battle DJ Crossfader Mechanics:**

  - **Transformer Cut (`SPACE`):** Clickless 2ms VCA fader gate.

  - **3-Finger Crab Scratch (`Z` / `X` / `C`):** Rapid multi-finger crab cuts.

  - **Hamster Switch (`H`):** Reverses the crossfader cut gate behavior for battle scratch routines.

- **Melankolia Boom-Bap Sequencer:** Built-in 16-step beat engine featuring a D-Phrygian melancholic Oud/Rhodes arpeggio, analog boom-bap drums, and deep sub-bass.

- **YouTube Stream Integration:** Load any YouTube track URL to perform live scratches over your favorite beats.

- **Pro DJ Mixer Section:** 3-Band Isolator EQ with instant `KILL` switches, Resonant Color Filter (`LPF / HPF`), Dub Delay, Ultra Pitch (`±16%`), and a 4-Pad MPC FX Sampler (`Q / W / E / R`).



### ⌨️ Keyboard & Trackpad Shortcuts



| Control / Key | Action |

| :--- | :--- |

| **Trackpad (Two-Finger Scroll)** | Forward (`FWD`) & Reverse (`REV`) vinyl scratch |

| **`SPACE`** | Transformer Cut (Instant VCA fader cut) |

| **`Z` / `X` / `C`** | 3-Finger Crab Scratch cuts |

| **`H`** | Hamster Switch (Reverse fader mode) |

| **`1` / `2` / `3` / `4`** | Switch Scratch Sample Banks (`AAHH`, `FRESH`, `BOOM SUB`, `SIREN`) |

| **`Q` / `W` / `E` / `R`** | Trigger MPC FX Pads (`HORN`, `VINYL BRAKE`, `808 SUB`, `LASER`) |



### 🚀 Quick Start

No build steps, servers, or dependencies required. Simply download and open `dj_turntable.html` in any modern web browser.
